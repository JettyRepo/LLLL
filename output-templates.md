# LLLL Output Templates v3.0

Aligned with the Embedded Compliance Layer architecture and compliance-checklist-master.md.

LLLL is an Embedded Compliance Layer — a Compliance Operating System.
It is NOT a legal tool. It is NOT a document generator.
It produces actionable compliance intelligence.

---

## User Subscription Levels

Basic, Pro, and Team are user subscription levels. All commands are available at every level. Deep (`/llll deep`) is a command mode, not a level.

| Level | Scope | Behavior |
|-------|-------|----------|
| **LLLL Basic** | Partial | Critical + High always shown. Medium/Low folded per rules below |
| **LLLL Pro** | Full | Full checklist, full matrix, full change tickets, complete action plan |
| **LLLL Team** | Full | Same content as Pro + organizational features (TODO P3: define Team-specific features) |

Deep mode (`/llll deep`) adds Sensitivity Assessment, Why This Matters Now, Consequences, and Human Review Flags at ALL levels. In Basic, these sections follow the same Medium/Low folding. In Pro and Team, deep output is identical and fully expanded.

### Output Mode Header

Every output begins with the user's subscription level:

```
Output Mode: LLLL Basic
Output Mode: LLLL Pro
Output Mode: LLLL Team
```

When running `/llll deep`, append the mode:

```
Output Mode: LLLL Pro — Deep Analysis
Output Mode: LLLL Basic — Deep Analysis
```

### Risk Levels

| Level | Meaning | Folded in Basic? |
|-------|---------|-----------------|
| **Critical** | Urgent + important — immediate serious consequences | Never |
| **High** | Important but not urgent — significant risk over time | Never |
| **Medium** | Weakens compliance posture — not immediately catastrophic | Yes |
| **Low** | Improves maturity — useful but not urgent | Yes |

### Basic Folding Rules

Critical and High items are **ALWAYS shown**. Only Medium and Low are folded:

1. **3+ items** in a risk level: fold 2, show the rest
2. **2 items** in a risk level: fold 1, show 1
3. **Exception**: if total Medium + Low ≤ 2, fold ALL Medium and Low

Marker: `(+N Medium/Low items hidden)`

Every output ends with:

```
⚠️ Disclaimer:
This content is generated by AI and may be incomplete or inaccurate.
Human compliance expert or legal professional review is recommended.
```

## Actionable Output Standard

Every output — regardless of subscription level — must include:

1. **What is missing** — specific gaps identified
2. **What to do next** — prioritized action items
3. **Who handles it** — owner assignment:
   - **Product** — business decisions
   - **Engineering** — technical confirmations
   - **Compliance expert / Legal professional** — regulatory and compliance questions
